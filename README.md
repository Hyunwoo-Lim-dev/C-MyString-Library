# C-MyString-Library
C언어 표준 문자열 라이브러리(string.h) 핵심 함수 10종 직접 구현 및 비교 검증 프로젝트

2026학년도 2학기 C프로그래밍 기말 프로젝트 (주제 9: 커스텀 문자열 라이브러리 구현)
C언어 표준 라이브러리(string.h)의 핵심 문자열 처리 함수 10종을 포인터와 배열 인덱스, 널 종료 문자('\0') 원리만으로 직접 설계·구현하고 표준 함수와 1:1 기능 동일성을 검증한 프로젝트입니다.

  1. 프로젝트 기본 정보
과목명: C프로그래밍 (담당교수: 서동만 교수님)
작성자 및 소유권: 임현우 (대구가톨릭대학교 컴퓨터소프트웨어학부 1학년, 학번: 26123541)
선정 주제: [난이도 中] <string.h> 대체 커스텀 문자열 라이브러리 my_string.h 구현 및 검증
개발 환경: macOS / Visual Studio Code / GCC Compiler / Git & GitHub

  2. 프로젝트 주제 선정 이유
1. 임베디드 및 스토리지 시스템 SW 기초 역량 확보 (진로 연계):
   향후 시스템 소프트웨어 및 스토리지(SSD) 펌웨어 분야 개발자를 목표로 공부하면서, 운영체제나 무거운 표준 라이브러리에 의존하지 않고 메모리 경계를 직접 통제하는 저수준 C 프로그래밍 역량이 필수적이라는 점을 깨달았습니다. 펌웨어 환경에서 빈번히 발생하는 고정 길이 버퍼 복사(strncpy), 상태 로그 결합(strncat), 제어 문자열 및 구분자 파싱(strstr, strspn,strcspn)을 직접 바닥부터 구현해 보며 메모리 안전성과 경계 조건 처리 감각을 익히기 위해 본 주제를 선정했습니다.
2. 문자열 처리의 내부 메커니즘 이해:
   평소 당연하게 호출하던 <string.h> 함수들이 내부적으로 널 문자('\0')를 어떻게 탐지하고 포인터 주소를 어떻게 이동시키는지 직접 구현해 봄으로써, 1학년 과정에서 배운 배열과 포인터 개념을 실제 라이브러리 단위로 체화하고자 했습니다.

  3. 관련 연구 (표준 <string.h> 분석 및 구현 범위 설정)
표준 <string.h> 헤더는 크게 복사(Copy), 병합(Concatenation), 비교(Comparison), 탐색(Search), 길이/메모리 제어 기능으로 구성됩니다. 본 프로젝트에서는 단순 전체 복사(strcpy)보다 버퍼 크기 제한과 포인터 위치 탐색이 요구되어 구현 난이도가 높은 8개 함수를 기본 대상으로 선정하고, 가산점 기준을 충족하기 위해 기초 함수 2종을 추가하여 총 10개 함수를 설계했습니다.

기본 구현 대상 (난이도 중/상 8종):my_strncpy, my_strncat, my_strncmp, my_strchr, my_strrchr, my_strstr, my_strspn, my_strcspn
추가 구현 대상 (기초 2종):my_strlen, my_strcmp
